# AI provider and model icons

Source: [`@lobehub/icons-static-svg`](https://www.npmjs.com/package/@lobehub/icons-static-svg) 1.95.1 ([lobehub/lobe-icons](https://github.com/lobehub/lobe-icons)), MIT License.

Each brand keeps one file:

- `<name>-color.svg`: the brand's color version, when it has one that works on light and dark backgrounds.
- `<name>.svg`: otherwise the monochrome version, `fill="currentColor"`, drawn in the text color.

The logos are trademarks of their respective owners and are used only to identify the provider or model.
