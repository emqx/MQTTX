# 备份与恢复

在 **设置 > 高级** 中点击 **数据备份**，可将连接设置和收发消息导出为 JSON、YAML、XML、CSV 或 Excel。通过 **数据恢复** 导入备份；恢复后连接保持断开状态。

JSON 备份保留嵌套与空分组、排序及连接归属，单连接导出还会包含其祖先分组。其他格式保持原有连接或消息结构，不包含分组。

## 格式兼容

JSON 沿用顶层数组，连接记录保留原有字段。分组记录格式如下：

```json
{
  "id": "collection-id",
  "name": "Production",
  "isCollection": true,
  "parentId": null,
  "orderId": 0
}
```

`parentId` 指向同一备份中的父分组；根分组使用 `null`。连接沿用 `parentId` 表示所属分组。恢复不依赖记录顺序。

恢复兼容旧版仅包含连接的备份。旧文件不包含分组实体，因此连接恢复到根层级。没有 ID 的旧连接会获得新 ID。旧版 MQTTX 无法导入包含分组记录的 JSON 文件，请使用支持分组备份的版本恢复此类文件。

## 重复导入与冲突

导入已存在的分组或连接 ID 会更新对应实体。消息 ID 更新该连接已有的消息，备份提供的订阅列表替换该连接的订阅。备份未包含的消息保留在数据库中。重复导入时保留 ID，可避免创建新实体。

恢复拒绝备份内重复的 ID、分组与连接共用的 ID、属于其他连接的子记录 ID、缺失的分组引用和循环层级。验证或数据库操作出错时，整个导入事务回滚，包括分组关系、连接、遗嘱、订阅和消息。
