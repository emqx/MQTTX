# MQTTX Agent

MQTTX Agent 是内置于 MQTTX 桌面客户端的助手。你用自然语言提出需求，它会通过工具来操作 MQTTX：创建并连接连接、订阅与发布、读取消息，以及调用你的 MCP 工具。每个操作都走 MQTTX 现有的代码路径，和手动操作一致，因此连接列表、订阅列表和消息列表会实时更新。

![MQTTX Agent 面板](/images/mqttx-agent.png)

## 开启与配置

1. 打开 **设置 → MQTTX Agent**，打开 **启用 MQTTX Agent**。
2. 填写你的服务商的 **API Host**、**API Key** 和 **模型**。常用地址：

| 服务商 | API Host |
| --- | --- |
| OpenAI | `https://api.openai.com/v1` |
| DeepSeek | `https://api.deepseek.com/v1` |
| Anthropic | `https://api.anthropic.com/v1` |
| xAI | `https://api.x.ai/v1` |
| Google | `https://generativelanguage.googleapis.com/v1beta` |
| SiliconFlow | `https://api.siliconflow.cn/v1` |
| Azure OpenAI | `https://<resourceName>.openai.azure.com` |

3. 通过左侧导航栏的星形按钮以全屏打开 Agent，或通过 `Cmd/Ctrl + J`、连接页或脚本页的 **MQTTX Agent** 按钮打开浮窗。

**推理强度**决定模型作答前思考多少。可以在 **设置 → MQTTX Agent → 推理强度** 中选择，也可以在输入框的模型菜单里、模型列表下方直接切换：**自动**交给服务商决定，**关闭**不进行推理，**低**到**最高**依次要求更多推理。当前档位会显示在模型名后面，不支持调节推理强度的模型会隐藏这一项。列表只显示当前模型支持的档位；如果它不支持你选的档位，会改用它最接近的一档。

Agent 有两种模式：覆盖主区域、让应用继续在后台运行的**全屏**，以及可在任何页面使用的**浮窗**。拖动标题栏可以移动浮窗，拖动边缘或角可以调整大小，位置和大小会被记住。用浮窗标题栏的展开按钮切换到全屏。按 `Esc` 关闭浮窗，全屏时按 `Esc` 回到浮窗。在左侧导航栏选择其他页面会退出全屏。

## 能做什么

- 列出并读取连接配置（含 TLS 证书和分组）
- 创建、修改、删除连接
- 连接与断开、订阅与取消订阅、以 Plaintext、JSON、Base64 或 Hex 发布消息，以及开始或停止定时发送
- 读取历史消息、等待新消息，以及清空某个连接的消息
- 在本地解析证书和私钥（内容不会发送给模型）
- 编写、测试并应用转换函数和编解码 Schema
- 构建和读取主题树
- 创建仪表盘和组件，并调整它们在仪表盘网格中的位置和大小
- 读取日志、修改应用设置
- 调用你配置的 MCP 工具

你可以直接说"连接到 broker.emqx.io 并订阅 `testtopic/#`"、"向 `mqttx/test` 发布一条 JSON 测试消息"，或"显示我的连接及状态"。在输入框中输入 `/` 可以选择技能（客户端代码、测试数据、编解码、自定义函数、MQTT/EMQX 知识、连接诊断或 MQTTX CLI），Agent 会按该技能完成任务。输入 `@` 可以提及连接：会弹出你的连接列表（当前正在查看的连接排在最前，已连接时显示绿点），用 `↑`/`↓` 和 `Enter` 选择，被提及的连接会随消息一起发出，Agent 会先用 `get_connection` 读取它再执行操作。生成的项目会保存成 zip：聊天里会显示文件卡片，可下载或在文件夹中显示。文件存放在应用数据目录的 `agent-files` 下，删除会话时会一并删除。

## 附件

你可以粘贴截图、把文件拖入面板，或点击 📎 选择文件。图片会发送给模型，文本文件以文本形式发送（超过 64 KB 的只发送前 64 KB），证书和私钥只发送路径，绝不发送内容。Agent 可以用这些文件配置 TLS，例如："用 `ca.crt` 作为 CA、`client.crt` 作为客户端证书、`client.key` 作为私钥，连接到 broker.example.com 的 8883 端口"。

## 权限模式

- **操作前询问**（默认）：读取自动执行；创建、连接、订阅、发布、删除以及全部 MCP 工具都会先请求批准。每个请求会显示一张卡片，可以选择**允许一次**、**本次对话中始终允许这个工具**或**拒绝**。
- **自动**：全部自动执行，不再询问。

可以在输入框的权限胶囊里切换（只影响当前会话），也可以在 **设置 → MQTTX Agent → 默认权限模式** 里设置默认值。第一次切到"自动"时，MQTTX 会提示风险让你确认。

## 步数上限

一次回复最多执行 **每次回复的最大步数** 个工具步骤（默认 50，范围 10–200，可在设置中修改）。达到上限时会暂停并显示**继续**按钮，点击后继续执行。

## 会话

面板会保存会话历史。全屏模式下会话列表在左侧；侧栏模式下从头部的历史按钮打开。你可以重命名会话（全屏下双击标题，或用 `···` 菜单），也可以连同消息一起删除。

会话变得很长时，Agent 会自动压缩较早的内容：把此前的对话总结成摘要，用摘要代替一条条旧消息继续工作，因此长会话也能继续。聊天里会出现一条「已压缩之前的对话」的分隔线，点击即可查看摘要；写摘要期间面板会显示「正在压缩对话…」。输入框下方的底栏会显示上下文窗口的占用情况：圆环加百分比，悬停可以看到 token 数量和自动压缩的临界点。来自上次回复的数字是实际值，带「约」的是估算值。

## MCP

在 **设置 → MQTTX Agent** 的 **MCP 服务器配置** 中配置 MCP server，同时支持 **Streamable HTTP** 和 **SSE** 的 URL：

```json
{
  "mcpServers": {
    "weather": { "url": "http://127.0.0.1:8000/mcp" },
    "legacy": { "url": "http://127.0.0.1:8001/sse" }
  }
}
```

在"操作前询问"模式下，每次 MCP 工具调用都会请求批准。

## 已知限制

- 收到的消息只在连接页面打开时才会存入 MQTTX。Agent 操作某个连接时会自动打开它的页面，所以 Agent 运行期间不受影响；其他连接的页面关闭时不会收集消息。

## 隐私说明

你的对话和工具调用结果会发送给你配置的模型服务商，以便它生成回复。工具读取连接时会遮盖已保存的密码、证书和私钥，但你在对话中输入的内容会原样发送，请避免在对话中输入密钥等敏感信息。
